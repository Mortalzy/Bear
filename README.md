# BEAR — производство из стеклопластика

Одностраничный React-лендинг по концепции №5 «Смелая геометрия»: жёлтый акцент, крупная типографика, светлая и тёмная темы. Сайт использует фотографии производства из материалов заказчика.

## Быстрый запуск

Установите **Node.js 24 LTS** (npm входит в комплект). Откройте терминал в папке проекта:

```bash
git clone https://github.com/Mortalzy/Bear.git
cd Bear
npm ci
npm run dev
```

Откройте **http://localhost:5173**. API работает на http://127.0.0.1:3001/api/health.
Если скачали через GitHub → Code → Download ZIP, сначала распакуйте архив, откройте папку `Bear-main` в VS Code и выполните `npm ci`, затем `npm run dev`.
Остановить приложение: `Ctrl+C`.

Для просмотра только лендинга без API:

```bash
npm run dev -w @bear/client
```

## Что готово

- Адаптивная страница: главный экран, 5 услуг, этапы работы, производство, партнёры, форма и контакты.
- Светлая и тёмная темы; выбор сохраняется в localStorage. По умолчанию светлая.
- Мобильное меню, якорная навигация и раскрывающиеся описания услуг.
- Телефон с маской +7, проверка обязательных полей и email.
- Добавление файлов через диалог или drag-and-drop, удаление вложений, проверки типа/количества/размера.
- До 5 файлов, максимум 50 000 000 байт (50 МБ) каждый; DWG, DXF, STEP, PDF, JPG.
- Места для контактов и карты, партнёры ООО «Регионпласт» и ООО «К-БОАТС». Имена партнёров представлены текстом, не официальными логотипами.
- Локальные шрифты Oswald и Inter, оптимизированные WebP-фотографии. Для отображения страницы внешние CDN не нужны.

## Статус формы

**Это версия для проверки дизайна. Онлайн-отправка ещё не подключена.**
Кнопка «Проверить заявку» выполняет только локальную валидацию. Она не отправляет письмо и не загружает файлы. После проверки показывается честное уведомление. Когда вы добавите email компании в `client/src/data/site.js`, появится ссылка для ручной отправки письма; файлы нужно будет приложить вручную.

API намеренно возвращает 503 на `POST /api/requests`, пока не подключены постоянное хранилище и SMTP. Не добавляйте SMTP-пароли во frontend или Git. Перед запуском отправки нужно согласовать политику обработки данных и настроить сервер.

## Сборка и проверки

```bash
npm test
npm run build
npm run preview -w @bear/client
```

Production-файлы создаются в `client/dist`. `npm start` запускает только API, не выдаёт frontend. Хостинг ещё не настроен. Черновик содержит `noindex, nofollow`; перед публикацией это нужно убрать после проверки контента.

## Где редактировать

| Путь | Назначение |
| --- | --- |
| `client/src/App.jsx` | Структура страницы, темы, меню, окно информации о данных |
| `client/src/App.module.css` | Макет, блоки и адаптивность |
| `client/src/styles/global.css` | Цветовые переменные, шрифты, базовые стили |
| `client/src/data/site.js` | Контакты, услуги и этапы |
| `client/src/features/request/` | Форма, маска телефона и её стили |
| `client/public/images/` | Фотографии проекта |
| `shared/src/index.js` | Общие ограничения вложений |
| `server/` | Заготовка Express API |

Секреты храните в `server/.env`, исключённом из Git. Поля для телефона, email, ФИО/названия, ИНН и ссылки на карту находятся в `client/src/data/site.js`; сейчас они пустые. Заполняйте их только тогда, когда готовы опубликовать эти данные в репозитории. Зависимости зафиксированы в `package-lock.json`; CI использует `npm ci`.
