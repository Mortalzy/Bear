# BEAR — производство из стеклопластика

Одностраничный React-лендинг по концепции №5 «Смелая геометрия»: зелёный акцент, крупная типографика, светлая и тёмная темы. Сайт использует фотографии производства из материалов заказчика.

## Быстрый запуск

Установите **Node.js 24 LTS** (npm входит в комплект). Откройте терминал в папке проекта:

```bash
git clone https://github.com/Mortalzy/Bear.git
cd Bear
npm ci
npm run dev
```

Откройте **http://localhost:5173**. API работает на http://127.0.0.1:3001/api/health.
Если скачали через GitHub → Code → Download ZIP, сначала распакуйте архив, откройте папку `Bear-main` в VS Code и выполните `npm ci`, затем `npm run dev`.
Остановить приложение: `Ctrl+C`.

Для просмотра только лендинга без API:

```bash
npm run dev -w @bear/client
```

## Что готово

- Адаптивная страница: главный экран, 5 услуг, этапы работы, производство, партнёры, форма и контакты.
- Светлая и тёмная темы с плавным переходом; выбор сохраняется в localStorage. По умолчанию светлая.
- Мобильное меню, якорная навигация, карусели фото и видео с плавной сменой слайдов и раскрывающиеся описания услуг. При настройке уменьшения анимации переходы отключаются.
- Телефон с маской +7, проверка обязательных полей и email.
- Добавление файлов через диалог или drag-and-drop, удаление вложений, проверки типа/количества/размера.
- До 5 файлов: каждый до 25 МБ, суммарно до 18 МБ; DWG, DXF, STEP, PDF, JPG.
- Два телефона и email в разделе заявки и футере, реквизиты ИП и ссылка на точку производства на карте; партнёры ООО «Регионпласт» и ООО «К-БОАТС». Имена партнёров представлены текстом, не официальными логотипами.
- Локальные шрифты Oswald и Inter, PNG-фотографии. Для отображения страницы внешние CDN не нужны.

## Настройка приёма заявок

Скопируйте `server/.env.example` в `server/.env`. Укажите SMTP-параметры и пароль приложения. По текущей схеме письма отправляются с `bear.fiberglass@mail.ru` на этот же ящик. Файлы отправляются **вложениями**, ссылки на скачивание и `PUBLIC_BASE_URL` не используются.

Перед включением формы выполните [инструкцию владельцу](docs/PRIVACY_LAUNCH.md): заполните домен, ОГРНИП, адрес оператора и данные обработчиков; утвердите документы, направьте/актуализируйте уведомление Роскомнадзора и подтвердите размещение всей схемы данных в РФ. Только после выполнения этих действий установите `PRIVACY_DOCUMENTS_APPROVED`, `RKN_NOTIFICATION_CONFIRMED`, `RU_DATA_LOCATION_CONFIRMED` в `true` и перезапустите API. Пока настройки неполны, форма выключена, API отвечает 503, документы явно помечены как проекты. Флаги не заменяют реальные действия владельца.

Политика находится на `/privacy`, отдельное согласие — на `/consent`. Vite проксирует их и `/api` к Express. На хостинге Nginx должен делать то же самое: [пример конфигурации](docs/nginx.conf.example). Production запускается с `NODE_ENV=production`, за локальным HTTPS-прокси и с каноническим `PUBLIC_SITE_URL`.

Форма отправляет `multipart/form-data` на `POST /api/requests`, с отдельным подтверждением согласия и текущей версией документов. Сервер проверяет настройки, согласие, поля, размеры и сигнатуры файлов. До отправки письма записывает закрытое подтверждение в `CONSENT_DIR` (по умолчанию `server/consents`); при ошибке записи письмо не отправляется. Вложения в `UPLOAD_DIR` (по умолчанию `server/storage`) удаляются после обработки. Оба каталога должны быть вне публичного root.

Срок рассмотрения обращения ограничен 90 днями до более раннего достижения цели/отзыва. Очистка журнала выполняется автоматически; настройте также ежедневное `npm run privacy:cleanup -w @bear/server` независимо от работы API. Досрочное удаление закрытой записи: `npm run privacy:delete -w @bear/server -- НОМЕР-ЗАЯВКИ`. Письма, почтовые вложения, цепочки, выгрузки и резервные копии приложение не удаляет: это обязанность оператора с документированием уничтожения. Полный порядок приведён в инструкции.

Для локальной проверки используйте только собственные тестовые данные. Автоматические тесты используют подставной SMTP и не посылают письма. Реальная доставка, конфигурация Nginx и российское размещение инфраструктуры требуют проверки на выбранном сервере; успешное `npm test` их не подтверждает.

## Видео в карусели

Каждая услуга использует файлы только из своей тематической папки в `client/public/images/`. Девять снимков из `Фото производства` распределены по трём каруселям раздела «Наше производство» — по три в каждой. В `client/src/data/site.js` у каждого слайда указан путь относительно `client/public/images/`, включая расширение. Например:

```js
{
  video: 'Матрицы и оснастка/1.mp4',
  poster: 'Матрицы и оснастка/2.png',
  alt: 'Матрицы и оснастка — видео',
},
```

`poster` — необязательный путь к существующему изображению. Видео запускается автоматически без звука, повторяется, не показывает элементы управления и останавливается при переходе на другой слайд. Пробелы и кириллица в путях кодируются при построении URL.

## Сборка и проверки

```bash
npm test
npm run build
npm run preview -w @bear/client
```

Production-файлы создаются в `client/dist`. `npm start` запускает только API, не выдаёт frontend. Хостинг ещё не настроен. Черновик содержит `noindex, nofollow`; перед публикацией это нужно убрать после проверки контента.

## Где редактировать

| Путь | Назначение |
| --- | --- |
| `client/src/App.jsx` | Структура страницы, темы, меню, ссылки на юридические документы |
| `client/src/App.module.css` | Макет, блоки и адаптивность |
| `client/src/styles/global.css` | Цветовые переменные, шрифты, базовые стили |
| `client/src/data/site.js` | Контакты, услуги и этапы |
| `client/src/features/request/` | Форма, маска телефона и её стили |
| `client/public/images/` | Фотографии проекта |
| `shared/src/index.js` | Общие ограничения вложений |
| `server/` | Express API, загрузка файлов, SMTP, юридические документы и журнал согласий |
| `shared/src/operator.js` | Известные публичные реквизиты владельца |
| `docs/PRIVACY_LAUNCH.md` | Действия владельца и подготовка инфраструктуры |

Секреты храните в `server/.env`, исключённом из Git. Публичные телефоны, email, юридическое имя, ИНН и координаты находятся в `client/src/data/site.js`. Ссылка на карте ведёт к точке по координатам, так как точный почтовый адрес ещё не предоставлен. Часы работы также пока не указаны. Зависимости зафиксированы в `package-lock.json`; CI использует `npm ci`.
